# 食不我予 ── 利用自動化團購系統解決餐點難抉擇、飲食趨勢問題
> **AI 驅動校園虛擬學餐網絡 (Virtual Dining Network, VDN)** · 知行合一期中專題報告互動展示平台

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen)](https://yaodechiang4181.github.io/Demo_html/)

---

## 📖 專案背景與核心議題
當校園核心集中式供餐設施（如男九學餐、松苑學餐）面臨整修暫停時，學生中午尖峰排隊長達 30–40 分鐘，餐廳選擇單一且容易造成供不應求。
本專案提出 **AI 驅動之校園虛擬學餐網絡 (VDN)**，透過「AI 需求預測 ➔ 智慧團購湊單 ➔ 校園熱點巡迴配送 ➔ 3 分鐘憑碼取餐」，將供餐由單點實體依賴轉化為去中心化、高彈性的校園供餐網絡。

---

## 🎨 視覺與美術風格設計
- **暖杏格紋紙質感 (Notebook Grid Paper)**：以暖米色 `#FFFAEB` 為基底，搭配細緻格紋紋理與手繪美食貼紙。
- **現代科技互動面板**：嵌入深色科技感毛玻璃控制台，呈現 AI 預測演算法與校園物流動畫。
- **簡報投影模式 (Presentation Mode)**：支援一鍵切換大螢幕全螢幕演講視野（支援 `ESC` 退出）。

## 🚀 核心章節與互動模組
1. **主題發想與供餐危機**：雙學餐整修衝擊與三方痛點對比（學生需求、餐飲供給、商家成本）。
2. **文獻基礎與企業韌性**：Linnenluecke (2017) 企管韌性 5 大流派 ➔ 聚焦「商業模式適應性」與「降低供應鏈脆弱性」三大原則（去中心化、模組化、具備緩衝）。
3. **動態能力 AI Flow (四部曲)**：Sensing 感知 ➔ Seizing 把握機會 ➔ Reconfiguring 重構物流。
4. **四大核心互動體驗區**：
   - 模組 01：**AI 需求預測模擬器**（天氣、考試週、活動人數調節）
   - 模組 02：**智慧湊單門檻模擬**（即時計算 10 份門檻解鎖批量免運）
   - 模組 03：**校園熱點巡迴物流**（SVG 地圖專車即時移動與動態取餐碼）
   - 模組 04：**成效可視化儀表板**（一般上課日 / 雨天情境 / 考試週尖峰數據切換）
5. **量化推演與韌性三角形**：
   - 排隊利用率模型：95% ➔ 減半暴增至 127%（消除學生隱形帳單）
   - 韌性三角形模型推估：供餐水準 $Q$ 由 71% 提升至 80%，60 天過渡期累積損失減少 **5,253 人·天**！
6. **預期挑戰與四維因應策略**：資料蒐集、AI 演算法、系統整合、韌性驗證之具體對策。
7. **三大推廣藍圖 (Blueprints 01–03)**：保障用餐權益、深化店家合作、跨校園模組化推廣。

## 🌐 本地預覽與部署
- **本地預覽**：直接以瀏覽器開啟 `index.html` 即可完整體驗所有動畫與互動。
